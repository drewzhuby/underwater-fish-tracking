# 结果来源与验证范围

历史检测比较取自本科论文表格。Faster R-CNN 的原始评估文件目前缺失，比较属于报告记载。650 张图像划分按论文记载，原视频到数据划分的完整清单缺失。

train63.csv 是独立保留的训练日志。epoch38 对应验证 mAP50=0.91990、mAP50–95=0.56783。该行不是论文比较表的 0.5676，不应混用。日志不能单独证明 150 张检验集的成绩、权重身份或重复实验稳定性。

原跟踪评价存在 IoU 门限和帧对齐口径问题，未发布跟踪精度提升数字。原光流实现用当前检测框中心采样前向光流，采样网格与帧归属存在局限。legacy 脚本保留原逻辑以便阅读。

本次验证覆盖合成增强和光流演示。检测与跟踪视频入口需使用者提供兼容权重和视频后另行验证。
